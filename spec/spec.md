# E-commerce CompFast
## Lado da Loja
Aplicação da Loja
- Usando Supabase
- Cruds:
	- Cadastro de Categorias de Produtos,
	- Cadastro de Produtos com foto (fotos salvas no BD)
	- Cupons de Descontos
	- Promoções (com data de expiração, por produto ou categoria)
- Gestão de:
	- Vendas
	- Clientes

## O que não precisa de ter na aplicação do lado da Loja
- Logística: código, rastreio, transportadora, etc
- Nota fiscal

## Lado do Cliente
SPA / PWA empacotado

- estilo mercado livre,
- lista de produtos, com destaque para as promoções,
- carrinho de compras,
- cadastro do cliente no primeiro checkout,
- persistências: Api do Supabase e localstorage,

## Identidade Visual
- estilo e cores semelhantes do MercadoLivre
